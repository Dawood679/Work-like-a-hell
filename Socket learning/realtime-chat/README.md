# Real-Time Chat Application

A beginner-friendly Socket.IO chat application built for learning purposes.

## Project Structure

```
realtime-chat/
├── server/                 # Backend code
│   ├── index.js           # Main server file
│   └── package.json       # Server dependencies
│
├── client/                 # Frontend code
│   ├── index.html         # Main HTML page
│   ├── styles.css         # Styling
│   └── app.js             # Client-side JavaScript
│
└── README.md              # This file
```

## How to Run

1. Start the server:
   ```bash
   cd server
   npm install
   npm start
   ```

2. Open `client/index.html` in your browser (or use Live Server)

## Learning Concepts Covered

- WebSocket fundamentals
- Socket.IO client-server connection
- Event-based communication (emit/on)
- Broadcasting messages
- User connection/disconnection handling
- Real-time UI updates
