📅 Day 1 – Arrays Basics

🔹 Array Kya Hota Hai?

Array same type ke data ko ek variable mein store karta hai. Jaise marks list ya roll numbers.

💡 Key Point: Array contiguous memory mein data store karta hai

🔹 Declaration & Initialization

// Declaration (size batao) int arr[5]; // Initialization (values do) int arr[5] = {1, 2, 3, 4, 5}; // Partial initialization (baaki 0 ho jayenge) int arr[5] = {1, 2}; // arr = {1, 2, 0, 0, 0}

🔹 Indexing (Array Access)

Array ka index 0 se start hota hai!

int arr[5] = {10, 20, 30, 40, 50}; arr[0] → 10 (First element) arr[1] → 20 (Second element) arr[4] → 50 (Last element) // ⚠️ arr[5] = ERROR! (Out of bounds)
⚠️ Array size 5 hai to valid index 0-4 tak hai!

🔹 Traversal (Loop se Access)

int arr[5] = {1, 2, 3, 4, 5}; // Array print karna for(int i = 0; i < 5; i++) { cout << arr[i] << " "; } // Output: 1 2 3 4 5

🔹 Sum of Array

int arr[5] = {1, 2, 3, 4, 5}; int sum = 0; for(int i = 0; i < 5; i++) { sum += arr[i]; } cout << "Sum = " << sum; // Output: 15

🔹 Maximum Element Find Karna

Pehle element ko max maan lo, phir baaki se compare karo

#include <iostream> using namespace std; int main() { int arr[3] = {1, 2, 3}; int max = arr[0]; // Pehle element ko max maano for(int i = 0; i < 3; i++) { if(arr[i] > max) { max = arr[i]; // Agar bada mile to update } } cout << "Maximum = " << max << endl; return 0; }

🔹 Minimum Element Find Karna

Same logic, bas condition ulta: arr[i] < min

#include <iostream> using namespace std; int main() { int arr[4] = {1, 2, 3, 0}; int min = arr[0]; // Pehle element ko min maano for(int i = 0; i < 4; i++) { if(arr[i] < min) { min = arr[i]; // Agar chota mile to update } } cout << "Minimum = " << min << endl; return 0; }

📌 Day 1 Quick Summary:

  • Array index 0 se start hota hai
  • Size n ho to last index = n-1
  • Max/Min: Pehle element se compare shuru karo
  • Loop se traverse: for(i=0; i<n; i++)

📅 Day 2 – 2D Arrays / Matrix

🔹 2D Array Syntax

2D Array = Rows × Columns (Table jaise)

// Declaration int a[3][3]; // 3 rows, 3 columns // Initialization int a[2][3] = { {1, 2, 3}, // Row 0 {4, 5, 6} // Row 1 }; // Access: a[row][col] // a[0][0] = 1, a[1][2] = 6

🔹 Matrix Visual Representation

        Col 0   Col 1   Col 2
        ─────   ─────   ─────
Row 0 │   1       2       3
Row 1 │   4       5       6
Row 2 │   7       8       9

📌 a[i][j] → i = row, j = column

🔹 Matrix Input / Output

#include<iostream> using namespace std; int main() { int a[3][3]; // INPUT cout << "Enter 9 numbers:" << endl; for(int row = 0; row < 3; row++) { for(int col = 0; col < 3; col++) { cin >> a[row][col]; } } // OUTPUT cout << "Matrix:" << endl; for(int row = 0; row < 3; row++) { for(int col = 0; col < 3; col++) { cout << a[row][col] << " "; } cout << endl; // New line after each row } return 0; }

🔹 Row-wise Traversal

➡️ Pehle row complete, phir next row

// Row-wise: Outer loop = row, Inner loop = col for(int i = 0; i < r; i++) { for(int j = 0; j < c; j++) { cout << a[i][j] << " "; } } // Output: 1 2 3 4 5 6 7 8 9 
Row-wise Output:
1 → 2 → 3   (Row 0)
4 → 5 → 6   (Row 1)
7 → 8 → 9   (Row 2)

🔹 Column-wise Traversal

⬇️ Pehle column complete, phir next column

// Column-wise: Outer loop = col, Inner loop = row for(int j = 0; j < c; j++) { for(int i = 0; i < r; i++) { cout << a[i][j] << " "; } } // Output: 1 4 7 2 5 8 3 6 9 
Column-wise Output:
1 ↓ 4 ↓ 7   (Col 0)
2 ↓ 5 ↓ 8   (Col 1)
3 ↓ 6 ↓ 9   (Col 2)

🔹 Row Sum (Har Row ka Sum)

for(int i = 0; i < r; i++) { int sum = 0; for(int j = 0; j < c; j++) { sum += a[i][j]; } cout << "Row " << i << " sum = " << sum << endl; } // Example for 3x3 matrix {1,2,3},{4,5,6},{7,8,9} // Row 0 sum = 6 // Row 1 sum = 15 // Row 2 sum = 24

🔹 Column Sum (Har Column ka Sum)

for(int j = 0; j < c; j++) { int sum = 0; for(int i = 0; i < r; i++) { sum += a[i][j]; } cout << "Col " << j << " sum = " << sum << endl; } // Example for 3x3 matrix {1,2,3},{4,5,6},{7,8,9} // Col 0 sum = 12 // Col 1 sum = 15 // Col 2 sum = 18

📌 Day 2 Golden Tricks:

  • a[i][j] → i = row, j = column
  • Horizontal move = column change (j++)
  • Vertical move = row change (i++)
  • Row-wise: outer loop row, inner loop col
  • Column-wise: outer loop col, inner loop row

📅 Day 3 – Array Reverse & Searching

🔹 Array Reverse (Simple Method)

End se start tak loop chala ke print karo

#include<iostream> using namespace std; int main() { int arr[3] = {1, 2, 3}; // Ulta loop: i = n-1 se 0 tak for(int i = 3-1; i >= 0; i--) { cout << arr[i] << " "; } // Output: 3 2 1 return 0; }

🔹 Linear Search (Element Dhundna)

Array mein element dhundna - ek ek karke check karo

#include<iostream> using namespace std; int main() { int arr[3] = {1, 2, 3}; int target = 2; bool found = false; for(int i = 0; i < 3; i++) { if(arr[i] == target) { found = true; cout << "Value mil gai at index " << i << endl; break; // Mil gaya to loop band } } if(!found) { cout << "Value nhi mili" << endl; } return 0; }

📌 Day 3 Key Points:

  • Reverse print: i = n-1 se 0 tak loop
  • Search: har element se compare karo
  • bool variable use karo found track karne ke liye
  • Element mile to break; lagao

📅 Day 4 – Sorting Check & Array Reverse (Swap Method)

🔹 Check if Array is Sorted

Har element ko previous se compare karo

#include<iostream> using namespace std; int main() { int arr[] = {1, 2, 3, 4, 5, 4, 6}; int n = 7; bool sorted = true; for(int i = 1; i < n; i++) { if(arr[i] < arr[i-1]) { // Current < Previous? sorted = false; cout << "Array is NOT sorted" << endl; break; } } if(sorted) { cout << "Array is sorted in Ascending order" << endl; } return 0; }

🔹 Sort 0s and 1s

0 aur 1 count karo, phir pehle 0 print karo, phir 1

#include<iostream> using namespace std; int main() { int arr[] = {1, 1, 1, 0, 0, 0, 0}; int n = 7; int count0 = 0, count1 = 0; // Count 0s and 1s for(int i = 0; i < n; i++) { if(arr[i] == 0) count0++; else count1++; } // Print sorted: pehle 0, phir 1 for(int i = 0; i < count0; i++) cout << 0 << " "; for(int i = 0; i < count1; i++) cout << 1 << " "; // Output: 0 0 0 0 1 1 1 return 0; }

🔹 Array Reverse (Two Pointer / Swap Method)

⭐ Important technique - Do pointers use karo

#include<iostream> using namespace std; int main() { int arr[] = {1, 2, 3, 4, 5}; int n = 5; int i = 0; // Start pointer int j = n - 1; // End pointer while(i < j) { // Swap arr[i] and arr[j] swap(arr[i], arr[j]); i++; // Move right j--; // Move left } // Print reversed array for(int k = 0; k < n; k++) { cout << arr[k] << " "; } // Output: 5 4 3 2 1 return 0; } 
Two Pointer Technique:

Initial:  [1, 2, 3, 4, 5]
           ↑           ↑
           i           j

Step 1:   [5, 2, 3, 4, 1]  (swap 1 & 5)
              ↑     ↑
              i     j

Step 2:   [5, 4, 3, 2, 1]  (swap 2 & 4)
                 ↑
               i=j (STOP!)

Final:    [5, 4, 3, 2, 1]

📌 Day 4 Key Points:

  • Sorted check: arr[i] >= arr[i-1] for ascending
  • 0/1 sort: Count karo, phir print karo
  • Two pointer reverse: i = 0, j = n-1, swap until i < j
  • swap(a, b) function C++ mein built-in hai

📅 Day 5 – Find Unique/Single Element

🔹 Find the Non-Duplicate Element

Array mein jo element sirf ek baar aaya ho use dhundho

#include<iostream> using namespace std; int main() { int arr[] = {2, 1, 9, 1, 2, 3, 9}; int n = 7; for(int i = 0; i < n; i++) { int target = arr[i]; int count = 0; // Count kitni baar aaya for(int j = 0; j < n; j++) { if(arr[j] == target) { count++; } } // Agar sirf 1 baar aaya if(count == 1) { cout << "Unique element: " << target << endl; break; } } // Output: Unique element: 3 return 0; }

🔹 Logic Explanation

Array: {2, 1, 9, 1, 2, 3, 9}

Element   Count   Unique?
───────   ─────   ───────
  2    →    2    →  No
  1    →    2    →  No
  9    →    2    →  No
  3    →    1    →  ✅ YES!

Answer: 3 (sirf ek baar aaya)

📌 Day 5 Key Points:

  • Nested loop use karo: outer for element, inner for counting
  • count == 1 matlab unique element
  • Time Complexity: O(n²) - Brute force approach
  • Better approach: XOR method (advanced)
